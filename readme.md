# Mondrian A

Para a recriação da composição III do Mondrian, comecei por colocar a imagem de referência no illustrator para perceber de forma mais clara as suas medidas. Tentei ser o mais rigorosa possível, no que toca às cores, medidas e alinhamentos. Utilizei o quad para formar os quadrados e o fill para os preencher com a cor correta. Utilizando o quaq consigo ter maior precisão na sua conceção, tendo de definir os oito parâmetros de cada um deles. Para a realização das linhas pretas, defini um strokeweight e tal como no quad, defini novamente onde queria que a linha começasse e terminasse juntamente com o seu comprimento e altura.
